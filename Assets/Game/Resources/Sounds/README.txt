Звуки драки. Каждый звук — своя папка, имя папки совпадает с Sfx:
﻿  Punch/  — удар кулаком (и попадание брошенным предметом)
﻿  Slap/   — лещ
﻿  Whoosh/ — бросок предмета
﻿  Impact/ — стук предмета об пол/стены
﻿  Miss/   — удар по воздуху (без файлов — тишина)
﻿Имена файлов внутри папки любые; если файлов несколько — выбирается случайный.
﻿Если папки нет или она пуста — играет сгенерированная кодом заглушка.
