Звуки драки. Имя файла должно начинаться с:
  punch  — удар кулаком (и попадание брошенным предметом)
  slap   — лещ
  whoosh — бросок предмета
  miss   — удар по воздуху (без файла — тишина)
  impact — стук предмета об пол/стены
Несколько вариантов (punch_1.wav, punch_2.wav...) выбираются случайно.
Если файлов нет — играют сгенерированные заглушки.
